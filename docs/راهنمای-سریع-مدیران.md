# راهنمای سریع مدیران و گردانندگان MafiaNights

این راهنما فقط امکانات و دستورهای مرتبط با نسخه جدید را پوشش می‌دهد.

## امنیت تغییر گرداننده

- تغییر گرداننده از بخش «مدیریت بازی ← تغییر گرداننده» فقط پیش از پخش نقش‌ها مجاز است.
- پس از پخش نقش‌ها، ربات تغییر گرداننده را رد می‌کند؛ حتی اگر مدیر گروه دکمه قدیمی یا پیام مدیریتی قبلی را باز کرده باشد.
- در صورت تغییر مجاز گرداننده، ربات برای گرداننده قبلی پیام خصوصی اطلاع‌رسانی می‌فرستد.
- اگر گرداننده قبلی گفت‌وگوی خصوصی ربات را شروع نکرده باشد، ممکن است تلگرام اجازه ارسال پیام خصوصی ندهد؛ تغییر گرداننده انجام می‌شود، اما تحویل پیام تضمین‌شده نیست.

## تذکر و مدیریت بازیکنان

دستورهای زیر را در گروه و با ریپلای روی پیام بازیکن هدف ارسال کنید. این عملیات‌ها فقط برای گرداننده بازی مجاز هستند؛ مدیر بودن در تلگرام به‌تنهایی کافی نیست.

| دستور | کاربرد |
|---|---|
| `تذکر` | ثبت یک تذکر برای بازیکن |
| `تذکر-` | حذف یک تذکر |
| `حذف تذکر` | حذف یک تذکر |
| `حذف تذکر 2` | حذف دو تذکر |
| `تذکر منفی` | نام دیگر دستور حذف تذکر |
| `تذکر منفی 2` | حذف دو تذکر |
| `کیک بازیکن` | اخراج بازیکن از بازی |
| `سکوت بازیکن` | سکوت بازیکن برای دور جاری |
| `ترن اضافه` | اعطای نوبت اضافه، در شرایط مجاز بازی |
| `جایگزین` | مدیریت جایگزینی بازیکن طبق وضعیت بازی |
| `تولد بازیکن` | ثبت تولد بازیکن |
| `حذف بازیکن` | خارج‌کردن بازیکن از بازی |

### مجازات خودکار

اگر تنظیمات مجازات خودکار فعال باشد، رسیدن به حد تعیین‌شده تذکر می‌تواند باعث سکوت انضباطی یا اخراج شود. ربات وضعیت مجازات را در گروه اعلام می‌کند و برای بازیکن نیز تلاش می‌کند پیام خصوصی بفرستد. دریافت پیام خصوصی به این بستگی دارد که کاربر بتواند از ربات پیام دریافت کند.

## نتیجه بازی در خصوصی

در گفت‌وگوی خصوصی ربات:

- `نتیجه بازی`
- `نتیجه`

این دستورها نتیجه آخرین بازی پایان‌یافته‌ای را که کاربر در آن شرکت کرده است باز می‌کنند. از دکمه‌های زیر پیام برای جابه‌جایی میان تب‌های **نتیجه، نقش‌ها و رتبه‌بندی** استفاده کنید.

## پروفایل، آمار و رتبه

| دستور | کاربرد |
|---|---|
| `پروفایل` | نمایش پروفایل خود |
| `آمار` | نمایش آمار خود |
| `رتبه` | نمایش رتبه‌بندی |
| همان دستور با ریپلای روی پیام بازیکن | مشاهده اطلاعات بازیکن هدف، در صورت پشتیبانی دستور از ریپلای |

## نکات عیب‌یابی

- اگر دستور مدیریتی رد شد، مطمئن شوید گرداننده بازی هستید و دستور را در گروه فعال اجرا می‌کنید.
- اگر تغییر گرداننده پس از پخش نقش‌ها رد شد، این رفتار امنیتی عمدی است.
- اگر نتیجه بازی در خصوصی نمایش داده نشد، ابتدا `/start` را برای ربات ارسال کنید و سپس دستور نتیجه را دوباره بفرستید.
- اگر پیام خصوصی مجازات یا تغییر گرداننده نرسید، ممکن است کاربر گفت‌وگوی خصوصی ربات را شروع نکرده باشد.
